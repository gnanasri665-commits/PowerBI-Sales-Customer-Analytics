# PowerBI-Sales-Customer-Analytics
Interactive Power BI dashboard for Sales Performance and Customer &amp; Lead Analysis.

Project Overview:
This project presents an interactive two-page Power BI dashboard designed to analyze sales performance, customer activity, and lead conversion.

Dashboard Pages:
1. Sales Performance Dashboard
Total Sales
Total Profit
Total Orders
Total Customers
Monthly Sales Trend
Sales by Category
Regional Sales Distribution
Top 5 Customers

2. Customer & Lead Analysis
Leads Won
Lead Conversion %
Average Delivery Days
Sales by Country
Profit by Category
Sales by Customer Name
Top 5 Products
Sales by Subcategory

Tools & Technologies:
Microsoft Power BI
Power Query
DAX
Data Modelling
Data Visualization
Skills Demonstrated
Data cleaning and transformation
Creating calculated measures using DAX
Building interactive dashboards
Analysing sales and customer performance
Presenting business information visually

Repository Contents:
Dashboard/ – Power BI report file (.pbix)
Screenshots/ – Dashboard screenshots
Documentation/ – Project documentation

How to View the Project:
Download the .pbix file from this repository.
Open it using Microsoft Power BI Desktop.
Explore both report pages and interact with the filters.
